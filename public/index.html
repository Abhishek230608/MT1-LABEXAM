Application Information

This page is statically stored inside the public/index.html directory and is dynamically read and served to your browser using Node's native fs.readFile() method when the /home route is accessed.

Part A: HTTP Endpoints

Running on http://localhost:3000

  • GET/ - Welcome HTML
  • GET/cart - Cart Items JSON
  • GET/about - About App Info
  • GET/home - Static index.html (FS)
  • POST/add-to-cart - Add Item

Part B: Express REST API

Running on http://localhost:4000

  • GET/cart - Retrieve all items
  • GET/cart/:id - Retrieve item by ID
  • POST/cart - Add new item
  • PUT/cart/:id - Update item
  • DELETE/cart/:id - Delete item
